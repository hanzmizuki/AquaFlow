# Mobile App Labs

Android lab projects built with Kotlin and Jetpack Compose.

| Lab | Description |
|-----|-------------|
| [Lab1](Lab1) | AquaFlow home screen UI: header, account card, promo card, rewards and bottom navigation |
| [Lab2](Lab2) | AquaFlow with a water usage tracker: text fields, buttons and state for logging usage against a monthly goal |

## Running

Each lab is a separate Android Studio project. Open the `Lab1` or `Lab2` folder (not this root folder) in Android Studio and run the `app` configuration.
